# Coming to the workshop

You will sign up for Mastra, Elastic, and Arcade during their respective sections. The
speakers will guide you through creating your projects and connecting them.

Bring a laptop, charger, access to your email for signup verification, and permission to
install development tools. GitHub access is needed for the starter and the hosted-project
flow; the Mastra section will cover it if you do not already have it.

The repo uses Bun 1.3.14, Python 3.11+ with uv for toolkits, and Node 22 for the
deployed web service. Optional advance downloads can save time, but no partner account, API key,
deployment, or completed cloud check is required before arrival.

The organizers still need to publish the tested operating-system instructions, any hosting
or billing requirements, the model-credential arrangement, and the remote support link.
Check those before the event once the guide is finalized.

At the workshop, follow:

1. [Mastra: build your first agent](modules/01-mastra.md).
2. [Elastic: prepare the account evidence](modules/02-elastic.md).
3. [Arcade: connect and govern](modules/03-arcade.md).
4. [Capstone: prove the complete workflow](modules/04-capstone.md).

Remote attendees follow the same sequence. A TA can help with setup during each section.

You can complete the approval exercise on your own. Use the demo's persona switcher to
request as Dana and approve as Riley. The Slack request arrives in your own account in the
workshop workspace. The supplied demo identities have their own credentials; you do not
need extra email inboxes or another attendee to play the approver. The solo path is implemented locally; its live rehearsal remains outstanding.
